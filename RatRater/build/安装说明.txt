RatRater 老鼠淘汰高亮 1.1.0
================================

安装
1. 退出游戏。
2. 把整个 build 文件夹里的两个文件（manifest.xml、RatRater.dll）放到一个新文件夹 RatRater，
   然后把这个 RatRater 文件夹复制到：
   D:\Probably Stolen\Mods\
   最终结构：D:\Probably Stolen\Mods\RatRater\manifest.xml 和 RatRater.dll
3. 启动游戏，主菜单点「模组 / Mods」，找到「老鼠淘汰高亮 / Rat Rater」，启用。
4. 按提示重启游戏，读档进入店铺，打开老鼠笼即可看到高亮。

用法
- 红色底色 = 建议淘汰（基因偏低 / 年长）
- 蓝色底色 = 怀孕母鼠，保护不判淘汰
- 绿色底色 = 优质留种
- H 键：开关全部高亮（默认开）
- [ / ] 键：调低 / 调高淘汰阈值（默认 0.50，越低越少老鼠被判淘汰）
- F11：导出鼠群清单 CSV 到存档目录的 RatRater 文件夹

死老鼠置底
- 整理背包 / 仓库时，死老鼠自动排到最后一格，活老鼠照常在前。
- 兼容多吉 R 键整理：它走游戏原生排序时死老鼠置底生效。
  如果 F4 面板里选了「智能排序」这类第三方方案，那套算法不经过游戏排序器，
  置底不生效——切回「原生 / Native」预设即可。

说明
- 只在老鼠所在格子上盖一层半透明底色，老鼠图案、存档都不改。
- 卸载：关闭游戏，删掉 Mods\RatRater 文件夹即可，存档不受影响。

排查
- 如果高亮没出现：存档目录 Player.log 里搜 [RatRater]，看 api 那行。
  store=True getAll=True isTag=True getTag=True traits=True 才表示接口全部命中。
  有 False 的项说明游戏版本接口名不同，把日志发回即可修。
- 死老鼠置底没生效：搜 `sortPatch`，正常应为 `sortPatch ok: ...<Sort>b__2`。
  若是 `comparator not found`，把日志发我，我按实际嵌套类名调整。
