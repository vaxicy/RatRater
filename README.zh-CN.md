# 深空当铺模组集合

[English](README.md) | **简体中文**

《深空当铺：可能是偷的》（**Probably Stolen**，Steam App 4348910）的原生 C# 模组集合，都用游戏自带的加载器，**不需要 MelonLoader**。

| 模组 | 说明 |
|---|---|
| [RatRater](RatRater/README.md) | 在鼠笼里高亮建议淘汰的老鼠，整理时红鼠和死鼠置底，用剥皮刀一键批量屠宰 |
| [WaterAutoLabel](WaterAutoLabel/README.md) | 水容器自动显示真实水质，不用再手动贴标签 |

每个模组都有自己的 README、源码、编译脚本和发布包，点上面的链接看功能、安装与排查说明。
