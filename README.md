# Probably Stolen Mods

**English** | [简体中文](README.zh-CN.md)

Native C# mods for **Probably Stolen** (Steam App 4348910), built with the game's built-in mod loader. **MelonLoader is not required.**

| Mod | Description |
|---|---|
| [RatRater](RatRater/README.md) | Highlights rats to cull right in the cage grid, sorts cull-flagged and dead rats to the end, and batch-butchers red/dead rats with a blade |
| [WaterAutoLabel](WaterAutoLabel/README.md) | Auto-labels water containers with their true quality — no manual labeling |

Each mod has its own README, source, build scripts and releases. See the links above for features, install steps and troubleshooting.
